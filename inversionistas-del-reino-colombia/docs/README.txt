FORMA DE USO
1. Sube la carpeta al repositorio o servidor estático.
2. Publica el sitio en GitHub Pages, Netlify o cualquier hosting estático.
3. Para actualizar el dashboard online, reemplaza el archivo data/dashboard.xlsx por la versión nueva del libro.
4. Recarga la página.

MODO ALTERNATIVO
- También puedes usar el botón "Cargar archivo local" para probar una versión nueva del Excel sin publicarlo.

REQUISITOS DEL EXCEL
- Hoja 1: Base Inversionistas 26
- Hoja 2: Gastos 26
- Encabezados en la fila 4

SUGERENCIAS DE EVOLUCIÓN
- Publicar la fuente en Google Sheets y exponerla vía Apps Script para refresco instantáneo.
- Agregar autenticación simple si el dashboard tendrá datos sensibles.
